# AWS Terraform Infrastructure

This project provisions AWS infrastructure using Terraform for a cloud administrator / cloud engineer workflow.

## Tech Stack
- AWS EC2
- AWS IAM
- AWS VPC
- AWS RDS
- AWS CloudWatch
- Security Groups
- Terraform
- Linux

## Architecture

Internet
→ Route 53
→ Application Load Balancer
→ EC2 Instances
→ RDS Database

## Features
- VPC with public and private subnets
- EC2 instance provisioning
- IAM role and policy configuration
- Security group rules
- RDS database setup
- CloudWatch monitoring
- Terraform variables and outputs

## Skills Demonstrated
AWS, Terraform, IAM, VPC, EC2, RDS, CloudWatch, Linux Administration, Infrastructure as Code
